# Electric Vehicle Data Analysis using Power BI

## Project Overview
This project focuses on analyzing Electric Vehicle (EV) data using Microsoft Power BI to identify trends, patterns, and insights in the electric vehicle market.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Visualization

## Data Cleaning & Transformation
The following operations were performed:
1. Renamed Electric Vehicle Type values.
2. Removed records with blank Vehicle Location.
3. Created Electric Range Bin (Low, Medium, High).
4. Extracted Latitude and Longitude from Vehicle Location.
5. Changed data types and prepared data for analysis.

## Key Analysis
- Total Electric Vehicles
- BEV vs PHEV Analysis
- Vehicle Manufacturer Analysis
- Electric Range Analysis
- Geographical Distribution of Electric Vehicles
